# ชุด skeleton อักษรไทยตาม Unicode

มีไฟล์ JSON หนึ่งไฟล์ต่อหนึ่ง codepoint ที่กำหนดไว้ในช่วงอักษรไทยที่ร้องขอ ตั้งชื่อไฟล์รูปแบบ `U+XXXX.json`

## รายการที่ครอบคลุม

- พยัญชนะ 44 ตัว รวม ง งู และพยัญชนะทุกตัวหลังจากนั้น
- ตัวอักษรและเครื่องหมายสระ 11 ตัว
- เครื่องหมายประกอบ 16 ตัว รวมวรรณยุกต์ทั้ง 4
- เครื่องหมายและสัญลักษณ์อื่น 6 ตัว
- เลขไทย 10 ตัว
- รวมไฟล์ JSON 87 ไฟล์

รายการอิงตามบล็อกอักษรไทยของ Unicode และไม่รวม codepoint ที่ยังไม่ได้กำหนด สระประสมเก็บแยกตามอักขระ Unicode แต่ `ำ` คงเป็นไฟล์เดียว เพราะเป็นอักขระหนึ่งตัว

## โครงสร้าง

```text
skeletons/
  consonants/U+0E01.json ...
  vowels/U+0E24.json ...
  marks/U+0E31.json ...
  symbols/U+0E2F.json ...
  digits/U+0E50.json ...
previews/
manifest.json
```

แต่ละ JSON รักษาโครงสร้างจากตัวอย่าง และเพิ่ม `unicode_name`, `category` กับ `placement` พิกัดใช้ canvas ขนาด 64 × 96 เครื่องหมายประกอบเก็บเป็นเส้นของตัวเอง และระบุตำแหน่งที่ต้องผูกกับพยัญชนะไว้ใน `placement`

## รูปทรงและการตรวจ

ไฟล์เก็บเส้นกลางที่สกัดจากรูปอักษรอ้างอิงแบบไทยมีหัวและห่วง แต่ละกิ่งของ skeleton แปลงเป็นเส้น cubic Bezier ภาพสีเทาอ่อนใน preview คือรูปอ้างอิง ส่วนเส้นสีน้ำเงินคือ skeleton ใน JSON ภาพ contact sheet ของทุกกลุ่มถูกตรวจเทียบเพื่อหาส่วนที่ขาดหรือคลาดตำแหน่ง

ไฟล์ ง งู ที่แก้แล้วเริ่มจากด้านบนซ้าย ลากลงทางซ้าย โค้งผ่านฐาน แล้ววกขึ้นเป็นตะขอด้านขวา ตามลำดับลักษณะของตัวอักษร ไม่ใช่เส้นโค้งที่จบลงทางขวาล่างเหมือนตัวอย่างเดิม

ค่า `pen_order` เรียงกิ่งตามตำแหน่งบนรูป ไม่ใช่ลำดับการยกและลากปากกาตามแบบเรียน เพราะ skeleton อาจมีกิ่งแยก และรูปอ้างอิงจากฟอนต์ไม่ได้เก็บลำดับการเขียนจริง ข้อจำกัดนี้ระบุไว้ใน `reference` และ `review` ของทุกไฟล์

## สุ่มรูปแบบด้วย seed

ไฟล์ JSON ทุกตัวมี `seed_variants` และมีตัวสุ่มที่ `tools/sample_seed.py` ใช้ seed สร้าง skeleton ที่เปลี่ยนรูปแบบได้ โดย seed และลำดับการปรากฏของตัวอักษรเป็นตัวกำหนดผลซ้ำได้ นิสัยการเขียนหัวจะเลือกจาก seed ระดับผู้เขียนหนึ่งครั้ง จึงใช้แบบมีวงหรือไม่มีหัวให้สอดคล้องกันกับตัวอักษรที่รองรับเกือบทุกตัวในข้อความเดียวกัน:

```sh
python3 tools/sample_seed.py --char ง --seed 42 --output /tmp/ngo.json
```

ผลลัพธ์เลือกทรงธรรมชาติ ตัวแบน หรือลดรูป พร้อมปรับความกว้าง ความสูง ความเอียง และความโค้งเล็กน้อย แนวทางการเขียนทั่วไปจัด `ก` และ `ธ` เป็นตัวไม่มีหัว ส่วนพยัญชนะอื่นมีหัวที่อาจเขียนเป็นปลายเปิดหรือวงได้ ([ใบความรู้การเขียนพยัญชนะ](https://sites.google.com/view/swanya/%E0%B9%81%E0%B8%9A%E0%B8%9A%E0%B8%9D%E0%B8%B6%E0%B8%81%E0%B8%97%E0%B8%81%E0%B8%A9%E0%B8%B0-%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B9%80%E0%B8%82%E0%B8%B5%E0%B8%A2%E0%B8%99%E0%B9%80%E0%B8%9E%E0%B8%B7%E0%B9%88%E0%B8%AD%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%AA%E0%B8%B7%E0%B9%88%E0%B8%AD%E0%B8%AA%E0%B8%B2%E0%B8%A3/%E0%B8%8A%E0%B8%B8%E0%B8%94%E0%B8%97%E0%B8%B5%E0%B9%88-1-%E0%B8%84%E0%B8%A7%E0%B8%B2%E0%B8%A1%E0%B8%A3%E0%B8%B9%E0%B9%89%E0%B9%80%E0%B8%9A%E0%B8%B7%E0%B9%89%E0%B8%AD%E0%B8%87%E0%B8%95%E0%B9%89%E0%B8%99-%E0%B9%80%E0%B8%81%E0%B8%B5%E0%B9%88%E0%B8%A2%E0%B8%A7%E0%B8%81%E0%B8%B1%E0%B8%9A%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%84%E0%B8%B1%E0%B8%94%E0%B8%A5%E0%B8%B2%E0%B8%A2%E0%B8%A1%E0%B8%B7%E0%B8%AD/%E0%B9%83%E0%B8%9A%E0%B8%84%E0%B8%A7%E0%B8%B2%E0%B8%A1%E0%B8%A3%E0%B8%B9%E0%B9%89)). ในชุดนี้ metadata ระบุหัวแบบไม่มีหัว 2 ตัว, ปลายเปิดตามรูปอ้างอิง 4 ตัว และวงปิดที่ sampler ตัดออกได้ทั้งวง 38 ตัว ส่วนสระ เครื่องหมาย และอักขระอื่นสุ่มเฉพาะรูปทรง โดยคงโครงสร้างหลักไว้ ตัวที่ไม่มีตัวเลือกหัวจะคงรูปอ้างอิงเดิม จึงเป็นข้อยกเว้นของนิสัยผู้เขียนได้

โค้ดที่เรียกใช้ร่วมกับโปรแกรมสร้างภาพได้:

```python
import json
from tools.sample_seed import sample_glyph

glyph = json.load(open("skeletons/consonants/U+0E07.json", encoding="utf-8"))
sampled = sample_glyph(glyph, seed=42, occurrence=0)
```

ใช้ `occurrence=0, 1, 2, ...` ให้ตัวอักษรซ้ำในข้อความเดียวกันได้ลายต่างกันแบบทำซ้ำได้ แต่ยังใช้นิสัยการเขียนหัวเดียวกันเมื่อใช้ seed เดิม ส่วน `sample_sequence(text, seed)` คืน skeleton ที่สุ่มแล้วของอักขระที่มีในชุดนี้ตามลำดับข้อความ

รูปแบบไม่มีหัวจะตัดเส้นวงหัวออกทั้งส่วน ไม่ได้เว้นช่องให้วงขาด ส่วนองค์ประกอบเฉพาะตัวอักษรเก็บแยกใน `optional_components` เช่น จะงอยของ `ก` และ `ถ` ที่สุ่มมีหรือไม่มีได้:

```sh
python3 tools/sample_seed.py --char ก --seed 42 --feature beak=present
python3 tools/write_thai.py ก --seed 42 --feature beak=absent --output ก-ไม่มีจะงอย.svg
python3 tools/write_thai.py ข --seed 42 --head-mode headless --output ข-ไม่มีหัว.svg
```

บังคับส่วนเสริมด้วย `--feature ID=present` หรือ `--feature ID=absent`; หากไม่ระบุ sampler จะเลือกสถานะจาก seed ให้อัตโนมัติ ส่วน `--head-mode looped` และ `--head-mode headless` ใช้เลือกแบบมีวงหัวหรือแบบตัดวงหัวออกทั้งส่วน เฉพาะตัวที่มีตัวเลือกหัว การเปลี่ยนสถานะจะเปลี่ยนเส้นใน JSON skeleton และโปรแกรมปลายทางยังต้องนำจุดกับ segments ไปวาดเป็นภาพ

## พิมพ์ข้อความแล้วสร้างไฟล์ลายมือ

ใช้ `tools/write_thai.py` เพื่อจัดวาง skeleton เป็นภาพเวกเตอร์ SVG รองรับอักขระที่อยู่ในชุดนี้ รวมพยัญชนะ สระ วรรณยุกต์ เครื่องหมาย และเลขไทย โดยจัดสระ/วรรณยุกต์ประกอบกับตัวฐาน:

```sh
python3 tools/write_thai.py สวัสดี
```

คำสั่งจะสร้าง `สวัสดี.svg` ในโฟลเดอร์ terminal ปัจจุบัน หรือเปิดแบบถามข้อความก่อน:

```sh
python3 tools/write_thai.py
```

กำหนด seed และที่บันทึกไฟล์ได้ เช่น:

```sh
python3 tools/write_thai.py สวัสดี --seed 42 --output สวัสดี.svg
```

เลือกบุคลิกลายมือให้คงแนวเดียวกันตลอดทั้งคำได้ด้วย `--persona`:

```sh
python3 tools/write_thai.py สวัสดี --persona slanted --seed 42 --output สวัสดี-เอียง.svg
```

มี `careful` (เป็นระเบียบ ตัวตั้ง), `rounded` (กลมและเส้นหนัก), `flat` (ตัวแบนและไม่มีหัว), `slanted` (เอียงขวา), `quick` (เขียนเร็ว ลดรูป) และ `messy` (เอียง สูงต่ำ ระยะห่าง และน้ำหนักเส้นแกว่งเป็นรายกลุ่มตัวอักษร) ตัวอย่างอยู่ใน `examples/personas/contact-sheet.svg` และไฟล์แยกในโฟลเดอร์เดียวกัน ส่วน `messy-seeds.svg` เทียบผลของ seed ที่ต่างกันสามค่า seed ทำให้รายละเอียดของแต่ละตัวเปลี่ยนซ้ำได้ โดยสระและวรรณยุกต์จะขยับไปพร้อมตัวอักษรฐานของกลุ่มนั้น

ตัวอย่างสุ่มรูปแบบชุ่ย:

```sh
python3 tools/write_thai.py สวัสดี --persona messy --seed 1 --output สวัสดี-ชุ่ย.svg
```

ตัวอย่างวงหัวและตัวอักษรที่ไม่มีหัวอยู่ที่ `examples/features/head-variants.svg`; ตัวอย่างจะงอยอยู่ที่ `examples/features/beak-variants.svg`. งานวิจัยด้านโครงสร้างอักษรไทยระบุจะงอยเป็นองค์ประกอบที่พบได้ใน `ก` และ `ถ` ([Burapha-TH](https://www.mdpi.com/2076-3417/12/8/4083)) ใน ก รูปแบบไม่มีจะงอยจะเหลือเส้นโค้งหลักและต่อขาซ้ายถึงฐานเป็นทรง U คว่ำ; ใน ถ จะตัดเฉพาะเส้นจะงอยสั้น ความยาว/สัดส่วนของจะงอยที่สุ่มเพิ่มเป็นตัวเลือกเชิงกระบวนการ ไม่ได้อ้างว่าเป็นมาตรฐานเดียวของลายมือไทย บุคลิกทั้งหมดเป็น preset ที่ปรับจาก skeleton ชุดนี้ ไม่ได้สร้างจากตัวอย่างลายมือของบุคคลจริง

สคริปต์ใช้ Python standard library อย่างเดียว ถ้ามี codepoint ที่ไม่มีในชุด จะบอกตัวอักษรที่ไม่รองรับแทนการข้ามเงียบ ๆ ดูตัวอย่างผลลัพธ์ที่ `examples/สวัสดี.svg`
